Move is the post-earnings reaction: a BMO print is measured from the prior session's close to the report-day close, an AMC print from the report-day close to the next session's close. Sigma puts that move in the stock's own trailing 252-day daily standard deviation, with the reaction day excluded. vs SPY is the same move net of the index over the identical window — which is what separates a real reaction from a tape move. EPS surp. is surprise against consensus, not growth, and is blank where consensus is missing or too near zero for a percentage to mean anything. Rev surp. is the same against revenue consensus.

YTD is total return from the last close of 2025 to the latest close — so for a company that has already reported it includes that post-earnings reaction. It answers “where does this stock stand now”, which is the only definition that also works for the names that have not reported yet. It is deliberately not the post-earnings-movers YTD, which stops at the print so it never includes the move it is explaining.

Status is binary on purpose. Confirmed means the date has positive evidence behind it — the company announced it, or an SEC filing corroborated it. Estimated means a provider projected it from historical cadence; treat it as a guess. A 📌 marks a date additionally pinned against provider drift, which is a note about the plumbing rather than a third grade of confidence.
